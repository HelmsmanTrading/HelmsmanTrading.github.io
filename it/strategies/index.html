Sviluppa Strategie

Un'architettura a plugin decentralizzata per quant e sviluppatori Python. Concentrati sul tuo alpha, noi gestiamo l'infrastruttura.

La Direttiva @register_skill

Most trading bots force you to write your logic inside a monolithic loop. Helmsman Trading turns this upside down. Strategies (called "Skills" internally) are fully decentralized.

To create a new trading algorithm, you simply create a Python file in the `skills` directory and inherit from `BaseSkill`. The framework dynamically scans this folder at startup, discovers your skill, instantiates it, and subscribes it to the L1 Data Lake.

  • Esegui più strategie contemporaneamente.
  • Crash-proof: Un'eccezione in una skill non ferma il framework.
  • Accedi nativamente agli indicatori SQLite in locale.
skills/vwap_reversion.py
from helmsman.skills import register_skill, BaseSkill
from helmsman.data.indicators import VWAP

@register_skill(name="VWAPReversion", interval="5m")
class VWAPReversionSkill(BaseSkill):
    
    def __init__(self):
        self.symbol = "SPY"
        self.vwap = VWAP(period="session")
        
    def on_data(self, data):
        current_price = data.get_price(self.symbol)
        vwap_value = self.vwap.get()
        
        # Mean reversion logic
        if current_price < vwap_value * 0.98:
            # L4 Risk Engine will validate this automatically
            self.submit_order(
                symbol=self.symbol,
                qty=100,
                side="buy"
            )

Guidato dagli Eventi

Niente while-loop incasinati. Le tue skill reagiscono nativamente agli eventi on_data, on_order_fill, ecc.

Esecuzione Type-Safe

Tutti gli ordini inviati vengono convertiti internamente in schemi Pydantic rigorosi prima di essere convalidati da L4 e inviati a L5.

Contesto di Portafoglio

Accedi allo stato globale senza sforzo. Chiama self.portfolio.heat per prendere decisioni di sizing dinamiche.
