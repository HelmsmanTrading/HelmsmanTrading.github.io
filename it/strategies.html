Scrivi Strategie

Un registro decentralizzato progettato per quant e sviluppatori.

La direttiva @register

Per creare una nuova strategia, non serve toccare il motore centrale. Basta aggiungere un file Python nella cartella skills e decorarlo.


from helmsman.skills import register_skill, BaseSkill

@register_skill(name="MovingAverageCrossover", interval="1m")
class MACrossover(BaseSkill):
    def on_data(self, data):
        # La tua logica algoritmica qui
        pass

Esecuzione Isolata

Ogni strategia gira nel proprio contesto. Se uno script crasha, il framework continua a funzionare. Il Risk Engine interviene chiudendo le posizioni se necessario.

Indicatori Nativi

Accedi a una vasta libreria di indicatori pre-calcolati nativamente dal Data Lake L1, senza dover importare librerie pesanti in ogni script.
