# `_brand/` — non è il sito

Questa cartella è **esclusa dalla build** Jekyll (`exclude: _brand` in `_config.yml`). Non diventa una pagina pubblica. È il tavolo interno: brandbook, token, regole per chi scrive copy o disegna.

| File | A cosa serve |
|---|---|
| [BRANDBOOK.md](BRANDBOOK.md) | Il libro. Perché Helmsman, doppia faccia, voce, segno, colore, tipo, layout, do/don't |
| [tokens.yml](tokens.yml) | Hex, type, spacing, da copiare in CSS/Tailwind — non da interpretare |
| [ADS.md](ADS.md) | Indice campagne (v1 plancia, v2 notte in coperta, v3 entra in coperta) |
| [ads/v1/board.html](ads/v1/board.html) | Mock v1 — sobria |
| [ads/v2/board.html](ads/v2/board.html) | Mock v2 — spettacolo della ghiera |
| [ads/v3/board.html](ads/v3/board.html) | Mock v3 — offerta e strumento, kit da comprare |

Prima di una pagina nuova, una tile, un ads, un pitch: apri il brandbook. Se una scelta contraddice un invariante, non è Helmsman. È un altro prodotto con il nostro oro incollato sopra.
