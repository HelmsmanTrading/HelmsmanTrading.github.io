Write Strategies

A decentralized Plugin Registry designed for quants and developers.

The @register Directive

To create a new trading strategy, you don't need to touch the core engine. Just drop a new file in the skills folder and decorate it.


from helmsman.skills import register_skill, BaseSkill

@register_skill(name="MovingAverageCrossover", interval="1m")
class MACrossover(BaseSkill):
    def on_data(self, data):
        # Your algorithmic logic here
        pass

Isolated Execution

Each strategy runs in its own context. If a strategy crashes due to a zero-division error, the rest of the framework keeps running. The Risk Engine steps in to flatten positions if necessary.

Native Indicators

Access a vast library of pre-calculated indicators natively from the L1 Data Lake without importing external heavy libraries in every script.
